# FactoryMind CDT — frontend

React 19 + TypeScript + Vite, TanStack Router (file-based routes in `src/routes`), TanStack Query,
Tailwind CSS v4, Vitest + Testing Library, Biome.

```bash
npm ci
npm run dev          # http://localhost:5173, proxies /api to FACTORYMIND_API_URL (default :8000)
npm test
npm run lint
npm run typecheck
npm run build
```

## API client

`src/api/generated/` is generated by orval from `openapi.json`, which is exported from the backend.
Do not edit it by hand. After changing backend routes or schemas:

```bash
cd ../backend && uv run python -m factorymind.api.openapi_export ../frontend/openapi.json
cd ../frontend && npm run generate:api
```

CI fails if either file is stale.
